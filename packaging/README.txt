Animax 1.0.0 — аниме-клиент для Windows
=====================================

Установка
---------
Запусти Animax-1.0.0-win64-setup.exe и следуй шагам мастера.

• Установка идёт в профиль пользователя (%LOCALAPPDATA%\Programs\Animax),
  права администратора не нужны.
• Ярлык появится в меню «Пуск»; по желанию — на рабочем столе.
• Удаление: Параметры Windows → Приложения → Animax → Удалить.
  Закладки и настройки в %APPDATA%\Animax при удалении сохраняются.

Если Windows покажет «Windows защитила ваш компьютер»:
нажми «Подробнее» → «Выполнить в любом случае». Это обычное предупреждение
для новых программ без цифровой подписи.

Переход с AnyX
--------------
Animax — продолжение AnyX. При первом запуске он сам переносит из %APPDATA%\AnyX
закладки, оценки, историю, настройки и вход в Shikimori. Если старый AnyX ещё
запущен, закрой его (значок в трее → «Выход»): оба используют порт 8790.

Если антивирус удаляет EXE
--------------------------
Однофайловая сборка PyInstaller иногда ложно определяется как
Trojan:Win32/Bearfoos.B!ml. Это эвристика, а не вирус. Варианты запуска
без такого EXE:
• «Запустить Animax.bat» — запускает pythonw.exe и Animax.pyw напрямую;
• «Создать ярлык Animax.bat» — создаёт удобный ярлык Animax на рабочем столе;
• папка Animax-portable (или Animax-1.0.0-portable.zip) — сборка «папкой»,
  без самораспаковки; Windows Defender проверяет её без угроз.

Что нужно
---------
• Windows 10 или 11 (64 бита; на ARM64 работает через эмуляцию x64).
• 4 ГБ памяти и 2 ядра — комфортно. На 2 ГБ приложение запустится,
  но будет медленнее: лёгкий режим включится сам.
• Microsoft Edge — в нём открывается окно Animax (в Windows 10/11 он уже есть).
• Интернет — каталог, озвучки и обложки загружаются онлайн.

Первый запуск может занять 2–5 секунд: exe распаковывает свои файлы во временную
папку. Если порт 8790 занят другой программой, Animax покажет окно с сообщением.
На слабом ПК (до 4 ГБ памяти или 1–2 ядра) автоматически включается лёгкий режим:
без анимаций, картинки 300 px, видео до 720p и без фонового подсчёта озвучек.

Как это работает
----------------
Animax запускает локальный сервер на 127.0.0.1:8790 и открывает окно приложения.
Крестик закрывает только окно — Animax остаётся в трее (у часов). Полностью
выключает «Выход» в приложении или в меню значка в трее.

Где хранятся данные
-------------------
%APPDATA%\Animax
  state.json   — закладки, оценки, настройки, история;
  auth.json    — вход через Shikimori (если настроен);
  cache\       — кэш обложек и ответов;
  error.log    — ошибка запуска, если она была;
  startup.log  — ошибка открытия окна, если она была.

Клавиши
-------
? — окно со всеми горячими клавишами (или кнопка ⌨ сверху).
Ctrl+K — поиск, F5 — обновить, Esc — назад/закрыть, F — полный экран в плеере,
Пробел — пауза, ←/→ — ±10 секунд, Shift+P / Shift+N — предыдущая/следующая серия.

Animax — личный клиент для просмотра аниме. Каталог и метаданные — Shikimori,
онлайн-озвучки — Anixart / AniLiberty / Kodik, свои файлы — из «Медиатеки».
Права на контент принадлежат соответствующим правообладателям.
