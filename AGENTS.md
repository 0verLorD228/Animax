# Animax — правила для ИИ-агентов

Этот файл читают оба агента: Claude Code (через `CLAUDE.md`) и DeepSeek Harness (сам). Здесь — только особенности
проекта. Общие правила совместной работы (ветки, доска задач, ревью, секреты) — в `~/.agents/AGENTS.md`, они действуют
и здесь. Комментарии, документацию и сообщения коммитов пишем по-русски.

## Что это
Десктопный аниме-клиент для Windows: Python-сервер на `127.0.0.1:8790` + интерфейс HTML/CSS/JS в окне Edge `--app`,
значок в трее, каталог Shikimori, онлайн-озвучки.

| Файл | Что внутри |
|---|---|
| `Animax.pyw` | запуск: один экземпляр, трей, окно, прогрев соединений |
| `server.py` | HTTP-сервер: API, статика, прокси картинок `/img`, защита Host/Origin, эксклюзивный порт |
| `shiki_net.py` | весь трафик к Shikimori: лимит запросов, пул keep-alive соединений, загрузка картинок |
| `shiki_data.py`, `shiki_auth.py`, `shiki_colls.py`, `reviews.py` | данные Shikimori, кэш, вход, коллекции, отзывы |
| `sources.py` | онлайн-озвучки (Kodik, Anixart, AniLiberty) |
| `state.py` | закладки и настройки, трёхстороннее слияние окон |
| `web/` | интерфейс: `index.html`, `js/*.js`, `css/` |

## Проверка
- Юнит-тесты, без интернета: `python -m unittest discover -s tests`. Должны проходить всегда.
- Интерфейс в браузере, нужны интернет и `pip install playwright`: `python tests/ui_smoke.py`.
- Сервер для ручной проверки — только с временной папкой данных, чтобы не тронуть настоящие закладки:
  PowerShell `$env:APPDATA = "$env:TEMP\animax-test"; python server.py 8799`.
- Настоящие данные пользователя (`%APPDATA%\Animax`) не читать и не менять.

## Правила кода
- Стиль — как в окружающем коде: короткие функции, комментарии по-русски объясняют «почему», а не «что».
- Новое поведение и исправленный баг — сначала тест, который падает, потом код.
- Секреты (токены, ключи, `client_secret`) в репозиторий не попадают: они живут в `%APPDATA%\Animax`.
- Зависимости не добавлять без нужды: сервер работает на стандартной библиотеке Python (+ Pillow по желанию).

## Работа вдвоём в этом проекте
Общие правила — `~/.agents/AGENTS.md`. Особенности Animax:
- Доска задач проекта — `C:\Users\OVER_\projects\Animax\TASKS.md` (только в основной папке, в git не хранится).
- Основная папка `C:\Users\OVER_\projects\Animax` (ветка `main`) — версия, которую запускает ярлык на рабочем столе.
  Рабочие папки агентов — рядом: `..\Animax-dsh-<задача>`, `..\Animax-claude-<задача>`.
- Перед слиянием в `main` обязательно зелёные `python -m unittest discover -s tests`; если менялись сеть или
  интерфейс — ещё и `python tests/ui_smoke.py`.
